**修复**：详见《接口文档》2.1.1 节

## 六、开发规范

### 6.1 云函数结构

```javascript
// cloudfunctions/xxx/index.js
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database();
const _ = db.command;

exports.main = async (event, context) => {
  const { action, payload } = event;
  const wxContext = cloud.getWXContext();
  const openid = wxContext.OPENID;
  
  try {
    if (action === 'xxx') {
      return await doXxx(payload, openid);
    }
    return { success: false, message: '未知 action: ' + action };
  } catch (err) {
    return { success: false, message: err.message || '操作失败' };
  }
};
```

### 6.2 返回格式

```javascript
// 成功
{ success: true, data: { ... }, message: 'ok' }

// 失败
{ success: false, message: '错误信息' }
```

### 6.3 前端调用

```javascript
const result = await wx.cloud.callFunction({
  name: '云函数名',
  data: {
    action: '动作名',
    payload: { /* 参数 */ }
  }
});

if (result.result.success) {
  // 成功
} else {
  // 失败
  wx.showToast({ title: result.result.message, icon: 'none' });
}
```

## 七、注意事项

### 7.1 必须注意

1. **先修复代报 bug**：这是紧急问题，用户已反馈
2. **按优先级开发**：P0 → P1 → P2
3. **开发完自测**：参考《测试用例文档》
4. **遇到问题沟通**：不要卡住，随时问

### 7.2 常见坑

1. **云数据库不支持联表**：需要多次查询 + 内存关联
2. **云函数冷启动**：首次调用可能较慢
3. **并发问题**：多人同时操作时注意数据一致性

### 7.3 参考代码

- **源项目**：`D:\project\badminton-app-java`（Java 实现，参考逻辑）
