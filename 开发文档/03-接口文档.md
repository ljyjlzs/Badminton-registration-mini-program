## 一、接口规范

### 1.1 请求格式

```javascript
{
  "action": "动作名称",
  "payload": {
    // 参数
  }
}
```

### 1.2 响应格式

```javascript
{
  "success": true/false,
  "data": {},      // 成功时返回
  "message": ""    // 错误时返回错误信息
}
```

### 1.3 调用方式

```javascript
const result = await wx.cloud.callFunction({
  name: '云函数名',
  data: {
    action: '动作名',
    payload: { /* 参数 */ }
  }
});
```

## 二、云函数接口

### 2.1 `join-activity`

#### 2.1.1 报名 (`action: 'join'`)

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `activityId` | String | 是 | 活动ID |
| `nickname` | String | 是 | 昵称（至少2个字符） |
| `avatar` | String | 否 | 头像URL（代报时可为空） |
| `level` | Number | 是 | 等级（1-10） |
| `partnerId` | String | 否 | 搭档ID（固搭模式） |
| `agent` | Boolean | 否 | 是否代报 |

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `registrationId` | String | 报名记录ID |
| `applyStatus` | String | 报名状态（'active' 或 'waiting'） |
| `isWaiting` | Boolean | 是否候补 |

**错误信息**：

| 错误信息 | 说明 |
|----------|------|
| `请输入有效的名字（至少2个字符）` | 昵称太短 |
| `请上传头像` | 非代报时缺少头像 |
| `等级必须在1-10之间` | 等级超出范围 |
| `活动ID不能为空` | 缺少活动ID |
| `活动不存在` | 活动ID无效 |
| `活动已开始或已结束，无法报名` | 活动状态不允许报名 |
| `您已报名此活动` | 用户已报名（非代报时） |
| `该姓名已在活动中报名` | 姓名重复（代报时） |
| `所选搭档尚未报名` | 搭档未报名 |
| `所选搭档已有搭档，请选择其他人` | 搭档已有搭档 |
| `您已被选为搭档，无需再报名` | 已被选为搭档 |

**示例**：

```javascript
// 普通报名
const result = await wx.cloud.callFunction({
  name: 'join-activity',
  data: {
    action: 'join',
    payload: {
      activityId: 'xxx',
      nickname: '张三',
      avatar: 'https://xxx.jpg',
      level: 5
    }
  }
});

// 代报
const result = await wx.cloud.callFunction({
  name: 'join-activity',
  data: {
    action: 'join',
    payload: {
      activityId: 'xxx',
      nickname: '李四',
      avatar: '',
      level: 3,
      agent: true
    }
  }
});
```

#### 2.1.2 冲突检测 (`action: 'check-conflict'`)

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `activityId` | String | 是 | 活动ID |

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `hasConflict` | Boolean | 是否有冲突 |
| `conflicts` | Array | 冲突活动列表 |

**冲突活动结构**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `activityId` | String | 活动ID |
| `name` | String | 活动名称 |
| `time` | Date | 活动时间 |
| `location` | String | 活动地点 |

**示例**：

```javascript
const result = await wx.cloud.callFunction({
  name: 'join-activity',
  data: {
    action: 'check-conflict',
    payload: {
      activityId: 'xxx'
    }
  }
});

if (result.result.data.hasConflict) {
  // 显示冲突提示
  wx.showModal({
    title: '时间冲突',
    content: `您在${result.result.data.conflicts[0].time}有其他活动，是否继续报名？`,
    success: (res) => {
      if (res.confirm) {
        // 继续报名
      }
    }
  });
}
```

### 2.2 `cancel-registration`

#### 2.2.1 取消报名 (`action: 'cancel'`)

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `activityId` | String | 是 | 活动ID |
| `reason` | String | 否 | 取消原因 |

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `activatedWaitlist` | Object | 被激活的候补用户（可选） |

**被激活的候补用户结构**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `userId` | String | 用户ID |
| `nickname` | String | 昵称 |

**错误信息**：

| 错误信息 | 说明 |
|----------|------|
| `活动ID不能为空` | 缺少活动ID |
| `您尚未报名此活动` | 用户未报名 |
| `活动已开始或已结束，无法取消` | 活动状态不允许取消 |

**示例**：

```javascript
const result = await wx.cloud.callFunction({
  name: 'cancel-registration',
  data: {
    action: 'cancel',
    payload: {
      activityId: 'xxx',
      reason: '临时有事'
    }
  }
});

if (result.result.success) {
  wx.showToast({ title: '取消成功' });
  
  if (result.result.data.activatedWaitlist) {
    wx.showToast({
      title: `${result.result.data.activatedWaitlist.nickname}已补位成功`,
      icon: 'none'
    });
  }
}
```

## 三、前端调用封装

### 3.1 统一调用函数

```javascript
// utils/cloud.js
async function callCloud(name, action, payload = {}) {
  try {
    const result = await wx.cloud.callFunction({
      name,
      data: { action, payload }
    });
    
    if (result.result.success) {
      return result.result.data;
    } else {
      throw new Error(result.result.message);
    }
  } catch (err) {
    console.error(`云函数调用失败：${name}.${action}`, err);
    throw err;
  }
}

module.exports = { callCloud };
```

### 3.2 使用示例

```javascript
const { callCloud } = require('../../utils/cloud');

// 报名
async function joinActivity(activityId, nickname, avatar, level) {
  try {
    const result = await callCloud('join-activity', 'join', {
      activityId,
      nickname,
      avatar,
      level
    });
    
    wx.showToast({ title: '报名成功' });
    return result;
  } catch (err) {
    wx.showToast({
      title: err.message,
      icon: 'none'
    });
  }
}

// 获取用户统计
async function getUserStats(period = 'season') {
  try {
    const stats = await callCloud('get-user-stats', 'get', { period });
    return stats;
  } catch (err) {
    wx.showToast({
      title: '获取统计失败',
      icon: 'none'
    });
    return null;
  }
}
```
