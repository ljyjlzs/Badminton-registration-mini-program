# 基础库兼容矩阵

> 第 10 章完整性复核维度 ⑤。记录基础库版本配置漂移与兼容性检查结果。

## 1. 版本配置现状

| 文件 | libVersion | 说明 |
|---|---|---|
| `project.config.json` | **3.15.0** | 公共配置，进仓库 |
| `project.private.config.json` | **3.17.2** | 私有配置，覆盖公共配置 |

微信开发者工具运行时以 **private 覆盖 public**，实际生效 **3.17.2**。两份文件不一致属团队配置同步问题（第七章 #35 已注明「本维度不报」），但需在兼容矩阵中留痕，避免各成员本地版本漂移。

## 2. 关键 API 最低基础库要求

| API / 特性 | 最低基础库 | 项目是否使用 | 备注 |
|---|---|---|---|
| `wx.cloud.init` / `callFunction` | 2.2.3 | 是 | 核心链路 |
| `wx.chooseMedia` | 2.10.0 | 是 | 拍照/选图 |
| `wx.chooseLocation` | 1.6.0 | 是 | `requiredPrivateInfos` 声明 |
| `wx.getRecorderManager` | 1.6.0 | 是 | 语音识别 |
| `wx.onNeedPrivacyAuthorization` | 2.32.3 | **未使用** | 隐私合规缺口，见维度 ① |
| `db.serverDate()` / `db.command.or` | 2.x | 是 | 云数据库 |
| `db.watch`（实时数据） | 2.x | 是 | activity-detail 比分实时推送 |
| `lazyCodeLoading: requiredComponents` | 2.11.1+ | 是（app.json） | 组件按需注入 |
| `wx.requirePrivacyAuthorize` | 2.32.3 | **未使用** | 同上 |

## 3. 兼容性结论

- 当前声明基础库 3.15.0 / 生效 3.17.2，均高于上述所有 API 最低要求，**无 API 兼容性阻塞**。
- 隐私相关 API（`onNeedPrivacyAuthorization` 等）要求 ≥ 2.32.3，当前版本满足，**只是代码没调用**。
- 建议：
  1. 把 `project.private.config.json` 的 `libVersion` 与 `project.config.json` 对齐到同一版本（推荐 3.17.2），消除私有覆盖带来的本地差异。
  2. 在 `app.json` 或最低基础库设置（`project.config.json` → `libVersion`）明确下限，避免旧版基础库用户命中未声明 API。
  3. 真机回归覆盖 iOS / Android 各一，重点验证录音、选图、定位三条隐私 API 链路。

## 4. 结论

**基础库兼容 = 无阻塞，但版本配置不一致，需统一。**
