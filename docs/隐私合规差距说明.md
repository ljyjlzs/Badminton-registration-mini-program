# 隐私合规差距说明

> 第 10 章完整性复核维度 ①。第七章检查点 #28 原判「无需补」→ 重判「未检查」，本文补扫后给出差距清单。

## 1. 隐私授权链路（全部缺失）

| 项 | 状态 | 证据 |
|---|---|---|
| `wx.onNeedPrivacyAuthorization` | 零命中 | 全仓 miniprogram + cloudfunctions |
| `wx.requirePrivacyAuthorize` | 零命中 | 同上 |
| `wx.getPrivacySetting` | 零命中 | 同上 |
| `wx.openPrivacyContract` | 零命中 | 同上 |
| 隐私协议弹窗 / 勾选同意 | 无 | 无任何页面处理授权回调 |
| `privacy.js` / `agreement.js` | 4 行空壳 | 仅 `Page({ data:{}, onLoad(){} })` |

结论：小程序使用了敏感 API，但未接入微信隐私协议授权流程。若在微信后台开启「用户隐私保护指引」强制校验，相关接口会被直接拦截。

## 2. 敏感 API 实测调用点

| API | 调用次数 | 位置 |
|---|---|---|
| `wx.chooseMedia` | 3 | `pages/activity-detail/activity-detail.js:282`、`pages/index/index.js:245`、`pages/photo-album/photo-album.js:331` |
| `wx.chooseLocation` | 1 | `pages/create-activity/create-activity.js:87`（另 `app.json:75` 声明 `requiredPrivateInfos`） |
| `wx.getRecorderManager` | 3 | `pages/activity-detail/activity-detail.js:857`、`pages/grouping/grouping.js:194`、`pages/voice-score-test/voice-score-test.js:18` |

**口径差异说明**：交接清单第七章 #28 原文写 `wx.chooseMedia×6 / getRecorderManager×4`；本次实测为 3/1/3。差异原因可能包括历史死代码（如 index.js 的 uploadAvatar、activity-detail.js 的 uploadAvatarForJoin 零 wxml 绑定）被并行清理或从未计入。以本文实测为准。

## 3. 现有配置（仅两项，不足）

- `miniprogram/app.json`：`requiredPrivateInfos: ["chooseLocation"]`、`permission.scope.userLocation`
- 无 `__usePrivacyCheck__`、无隐私协议页、无授权引导

## 4. 差距与建议

1. 补隐私协议页（`privacy` / `agreement` 目前是空壳），文案需覆盖：位置、摄像头/相册、麦克风。
2. 在 `app.json` 或全局 `App.onLaunch` 接入 `wx.onNeedPrivacyAuthorization`，弹出协议确认后再放行敏感 API。
3. 微信后台「小程序用户隐私保护指引」逐项声明：位置信息、选中的照片或视频、麦克风。
4. `voice-score-test` 属测试页，建议从生产包剔除，减少麦克风接口暴露面。

## 5. 注销/退出登录权（实测结论）

| 项 | 状态 | 证据 |
|---|---|---|
| 用户注销入口 | **无** | 全仓 miniprogram + cloudfunctions grep「注销 / 退出登录 / deleteAccount / closeAccount / logout」零命中 |
| 微信 `wx.login` / session 管理 | 仅 openid 静默获取 | `login` 云函数，无 session 过期/清除逻辑 |
| 账号数据清除 | **无** | 无任何云函数提供用户级数据删除操作 |

结论：**注销权未实现**。用户账号一旦创建（openid 生成），无法在小程序内注销或删除个人数据，不满足个人信息保护法「删除权」要求。需补：① 提供注销入口（前端+云函数）② 级联清除 users / registrations / scores / rating_changes 等个人数据 ③ 或明确以「联系客服注销」形式给出线下渠道。

## 6. 结论

**隐私合规 = 未检查完成 / 当前不合规**。第七章 #28 保持「未检查」判定。隐私授权链路、协议页、注销权均缺失，待补上后再复评。
