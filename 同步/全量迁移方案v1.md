> 编写时间：2026-09-04

## 一、架构差异（根本问题）

| 维度 | Java 项目 | 当前小程序 |
|------|----------|-----------|
| **API 调用** | `wx.request` + HTTP REST API | `wx.cloud.callFunction` + 云函数 |
| **请求封装** | `utils/request.js` → `get/post/put/del` | `utils/request.js` → `callFunction` |
| **认证方式** | JWT Token（`Authorization: Bearer xxx`） | 云开发自动鉴权（无需 Token） |
| **后端** | Spring Boot + MySQL | 云函数 + 云数据库 |

**结论：前端代码不能直接复制粘贴，必须把所有 HTTP API 调用改为云函数调用。**

## 二、当前小程序前端问题清单

### 问题 1：使用了 Java 项目的 HTTP 请求方式（报错根源）

当前小程序的 `utils/request.js` 是 `callFunction` 封装，但有些页面直接复制了 Java 代码，用了 `get/post/put/del`（HTTP 方式），导致报错。

**涉及文件（必须全部检查）：**
- 所有 `pages/*/` 下的 `.js` 文件
- 所有 `components/*/` 下的 `.js` 文件

### 问题 2：ES6+ 语法不兼容

以下语法在旧版微信开发者工具或基础库 < 2.9.0 中会报错：

| 语法 | 问题 | 替代写法 |
|------|------|---------|
| `?.`（可选链） | 部分基础库不支持 | `a && a.b && a.b.c` |
| `??`（空值合并） | 部分基础库不支持 | `a != null ? a : default` |
| `...`（展开运算符） | 对象展开在 setData 中可能有问题 | `Object.assign({}, a, b)` |
| 箭头函数 `=>` | 在 `success` 回调中 `this` 指向问题 | 用 `var self = this` + `function` |
| `const/let` | 某些场景下有作用域问题 | 统一用 `var`（保守方案） |
| 模板字符串 `` `${x}` `` | 旧版基础库不支持 | 字符串拼接 `'' + x` |

## 四、迁移策略（三种方案对比）

| 方案 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| **A：全部用云函数** | 前端只调 `callFunction` | 架构统一、无跨域问题 | 云函数数量多、维护成本高 |
| **B：HTTP API 网关** | 云开发 HTTP 访问服务 → Java 后端 | 复用 Java 后端、前端改动小 | 需要部署 Java 后端、有延迟 |
| **C：混合方案** | 核心用云函数、复杂用 HTTP | 灵活 | 两套架构、维护复杂 |

### 推荐方案：A（全部用云函数）

**理由：**
1. 已有 54 个云函数，架构已定
2. 云开发免费额度足够
3. 无需维护独立 Java 后端服务器
4. 微信生态内性能最优

## 六、代码兼容性改造规则

### 规则 1：请求方式改造

```javascript
// ❌ Java 项目写法（HTTP）
const { get, post, put, del } = require('../../utils/request');
get(`/activity/${id}`, null, { showLoading: false })
post('/registration/join', payload)
put('/match/score/modify', payload)

// ✅ 小程序写法（云函数）
const { callFunction } = require('../../utils/request');
callFunction('get-activity-detail', 'detail', { activityId: id })
callFunction('join-activity', 'join', payload)
callFunction('submit-score', 'modify', payload)
```

### 规则 2：可选链改造

```javascript
// ❌ Java 项目写法
const level = this.data.userRegistration?.level || 5;
const name = data.activity?.name || '';

// ✅ 小程序写法
const level = (this.data.userRegistration && this.data.userRegistration.level) || 5;
const name = (data.activity && data.activity.name) || '';
```

### 规则 3：箭头函数改造

```javascript
// ❌ Java 项目写法
success: (res) => {
  this.setData({ loading: false });
}

// ✅ 小程序写法（保持一致，但注意回调中的 this）
var self = this;
success: function(res) {
  self.setData({ loading: false });
}
```

### 规则 4：模板字符串改造

```javascript
// ❌ Java 项目写法
url: `/pages/match-score/match-score?activityId=${this.data.activityId}&matchId=${matchId}`

// ✅ 小程序写法
url: '/pages/match-score/match-score?activityId=' + this.data.activityId + '&matchId=' + matchId
```

### 规则 5：展开运算符改造

```javascript
// ❌ Java 项目写法
this.setData({ ...snapshot, 'aiSuggestion.show': false });

// ✅ 小程序写法
var data = Object.assign({}, snapshot, { 'aiSuggestion.show': false });
this.setData(data);
```

### 规则 6：async/await 改造

```javascript
// ❌ Java 项目写法
doStartAllMatches: async function(matches) {
  for (const match of matches) {
    await post('/match/start', { ... });
  }
}

// ✅ 小程序写法（用 Promise 链或递归）
doStartAllMatches: function(matches) {
  var self = this;
  var chain = Promise.resolve();
  matches.forEach(function(match) {
    chain = chain.then(function() {
      return callFunction('match-start', 'start', { activityId: self.data.activityId, matchId: match.id });
    });
  });
  chain.then(function() { /* 完成 */ });
}
```
