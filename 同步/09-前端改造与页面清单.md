# 09-前端改造与页面清单

> 目标：把 badminton-app-java 前端页面（miniprogram/pages/*）迁移到 badminton-app，调用层统一改为云函数。
> 仓库：D:\project\badminton-app（分支 sync-java-backend）。

## 9.1 调用层改造（必做）
在 `miniprogram/utils/request.js` 新增：
```js
function callFunction(name, action, data = {}) {
  return wx.cloud.callFunction({ name, data: { action, payload: data } })
    .then(res => {
      const r = res.result || {};
      if (r.success) return r.data;
      return Promise.reject(new Error(r.message || '请求失败'));
    });
}
module.exports = { callFunction, request };
```
- 全站页面用 `callFunction('create-activity','create',payload)` 风格替换原 `wx.request` 直连后端。
- 原有云函数调用（login/activity-detail 等）保持，仅补齐 `action` 分组。
