# 07-语音天气提醒模块（配置已对齐 Java 源码）

> 覆盖：`voice-score-config`、`voice-score-parse`、`weather`；实时提醒/现场比分见 03.5/03.6。
> 对齐 `VoiceScoreServiceImpl` / `WeatherServiceImpl` / `MatchReminderServiceImpl`。
> **关键修正**：语音配额 10/30/200 按滚动 1 小时窗口；needReview 阈值 0.85（0.60 为“重点核对”）；仅接受 mp3；识别不可用统一返回“请手动输入”。

## 7.1 voice-score-config（配置，对齐 VoiceScoreServiceImpl）
```
asrEnabled = ${asr.enabled:false}（未配置→OFF，入口禁用）
MAX_FILE_SIZE = 2MB
maxDurationSeconds = 60；recommendedDurationSeconds = 15
acceptedFormats = ["mp3"]
配额（滚动 1 小时窗口，三维度同时计、取剩余最小值）：
  USER_HOURLY_LIMIT   = 10    // 每用户每活动每场
  MATCH_HOURLY_LIMIT  = 30    // 每场
  ACTIVITY_HOURLY_LIMIT = 200  // 每活动
disabledReason ∈ {OFF, NOT_CONFIGURED, NO_QUOTA}
```
- 返回 `enabled / maxDurationSeconds / maxFileSizeBytes / acceptedFormats / remainingQuota / disabledReason`。

## 7.2 voice-score-parse（语音识别 → 比分，对齐 parseVoice/parseActivityVoice）
**前置**：`asrEnabled && asrService.isReady()`，否则 `BusinessException("语音识别暂不可用，请手动输入")`。
**频控**：先查 1 小时窗口计数，任一维度达上限即 `429 识别次数已达上限`；成功/失败请求均计入。
**步骤**
1. 校验文件：非空、≤2MB、`.mp3`。
2. `asrService.transcribe` → `text` + `asrConfidence`。
3. `ScoreVoiceParser.parse(text, asrConfidence, team1Label, team2Label)`：
   - 从文本提取 `team1Score/team2Score`（正则匹配比分，结合队伍标签/“队伍1/队伍2”或成员名）。
   - `sourceWeight` 由来源置信度给出。
4. `finalConfidence = min(asrConfidence,1.0) * sourceWeight`。
   - `needReview = finalConfidence < 0.85`；若 `finalConfidence < 0.60` 额外提示“识别不确定，请重点核对”。
5. 成功返回 `{team1Score, team2Score, confidence, needReview, message}`；AI 解析失败/无比分 → `BusinessException("没听清比分，请手动输入")`。
6. `needReview=false` 可直调 03.3 `submit-score`；`true` 前端二次确认。
- 审计：每次解析写 `voice_parse_logs`（不论成败），用于频控与排查。

## 7.3 weather（天气，对齐 WeatherServiceImpl）
**入参** `{ location(经纬度或地名), date }`
- `WEATHER_PROVIDER='amap'` → 高德；否则 `open-meteo`（默认）。
- 返回 `{ temp, weatherText, wind, code, suitable }`；`suitable` 为三档启发式（风力单位 m/s）：
  - **poor**：气温≥38℃ 或 ≤0℃、风力≥17.2（≈8 级）、降水≥5mm、降水概率≥85%、或雷暴/大暴雨码（95/96/99/65/82）。
  - **caution**：34–38℃、0–5℃、10–12℃、降水 0–5mm、降水概率 60–85%、风力 10.8–17.2（≈6–7 级）、或雨夹雪/小到中雨雪码（51/53/55/56/57/61/63/66/71/73/75/77/80/81/85/86）。
  - **suitable**：其余情况（气温约 5–34℃、无不利天气、风力 <10.8）。
- 失败降级 `{ suitable:true, weatherText:'天气未知' }`（不阻断报名/选场）。
