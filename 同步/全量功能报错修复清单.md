# 全量功能报错修复清单 — 逐链路排查结果

> 排查时间：2026-09-09
> 方法：对每个页面的每个 callFunction 调用，追踪 前端JS → 云函数 → action → 参数 → 返回值 的完整链路

## 一、问题总览（13 个问题）

| 类别 | 数量 | 说明 |

## 二、逐项详情

### 问题 1：语音填分 — action 不存在

**链路：**
- 前端 `grouping.js:216` → `callFunction('voice-score-parse', 'recognize', { fileID, activityId })`
- 云函数 `voice-score-parse/index.js` 支持的 action：`asr`、`parse`
- **`recognize` 不存在**

**修复：** 前端改为调用 `asr` action

---

### 问题 2：清除现场比分 — action 不存在

**链路：**
- 前端 `match-score.js:193` → `callFunction('match-live-score', 'clear', { matchId })`
- 云函数 `match-live-score/index.js` 支持的 action：`get`、`update`
- **`clear` 不存在**

**修复：** 云函数增加 `clear` action

---

### 问题 3：智能推荐时间 — action 不匹配

- **前端传 `suggest`，云函数要求 `recommend`**

**修复：** 前端改为调用 `recommend` action

### 问题 7：AI 文案 — 返回值格式不匹配

**链路：**
- 前端 `activity-detail.js:721` → `callFunction('generate-copy', 'generate', { activityId })`
- 云函数返回 `{ success: true, data: { copy: { announcement, share, invite } } }`
- 前端读取 `data.announcement`、`data.share`、`data.invite`
- **实际数据在 `data.copy.announcement` 等**

**修复：** 前端改为读取 `data.copy.announcement` 等

---

### 问题 8：现场比分同步 — 参数名不匹配

**链路：**
- 前端 `match-score.js:175-178` → 传 `team1Score`、`team2Score`
- 云函数 `match-live-score/index.js:27` → 读 `teamAScore`、`teamBScore`
- **参数名不同**

**修复：** 前端改为传 `teamAScore`、`teamBScore`

---

### 问题 9：现场比分权限检查 — 字段不存在

**链路：**
- 云函数 `match-live-score/index.js:31` → 检查 `match.data.organizerId`
- 但 `matches` 集合的文档没有 `organizerId` 字段（只有 `activityId`）
- **权限检查永远失败**

**修复：** 改为通过 `activityId` 查 `activities` 集合获取 `organizerId`
