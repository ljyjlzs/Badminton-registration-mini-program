## 一、已确认的报错问题（6 个）

### 问题 1：AI 文案弹窗显示空白

**链路追踪：**
- 前端 `activity-detail.js:721` 调用 `callFunction('generate-copy', 'generate', { activityId })`
- 云函数 `generate-copy/index.js:89` 返回 `{ success: true, data: { copy: doc } }`
- 前端 `activity-detail.js:726` 读取 `data.announcement`、`data.share`、`data.invite`
- **实际数据在 `data.copy.announcement`、`data.copy.share`、`data.copy.invite`**

**修复方法：** 修改 `activity-detail.js:724-729`，改为：
```javascript
var copyData = data.copy || data;
self.setData({
  aiCopyLoading: false,
  aiCopyAnnouncement: copyData.announcement || '',
  aiCopyShare: copyData.share || '',
  aiCopyInvite: copyData.invite || '',
  aiCopyText: copyData.announcement || ''
});
```

### 问题 2：现场比分同步报错（参数名不匹配）

**链路追踪：**
- 前端 `match-score.js:175-178` 调用 `callFunction('match-live-score', 'update', { matchId, team1Score, team2Score })`
- 云函数 `match-live-score/index.js:27` 读取 `payload.teamAScore`、`payload.teamBScore`
- **前端传 `team1Score`/`team2Score`，云函数读 `teamAScore`/`teamBScore` → 参数名不匹配**

**修复方法：** 修改 `match-score.js:175-178`，改为：
```javascript
callFunction('match-live-score', 'update', {
  activityId: self.data.activityId,
  matchId: self.data.matchId,
  teamAScore: self.data.team1Score,
  teamBScore: self.data.team2Score
})
```

---

### 问题 3：清除现场比分报错（action 不存在）

**链路追踪：**
- 前端 `match-score.js:193` 调用 `callFunction('match-live-score', 'clear', { matchId })`
- 云函数 `match-live-score/index.js:13` 只支持 `get` 和 `update` action
- **`clear` action 不存在 → 返回 "未知 action: clear"**

**修复方法：** 修改云函数 `match-live-score/index.js`，增加 `clear` action：
```javascript
if (action === 'clear') {
  const { matchId } = payload;
  if (!matchId) return { success: false, message: 'matchId 不能为空' };
  await db.collection('match_live_states').where({ matchId }).remove();
  return { success: true, message: '已清除' };
}
```

---

### 问题 4：现场比分权限检查永远失败

**链路追踪：**
- 云函数 `match-live-score/index.js:31` 检查 `match.data.organizerId !== openid`
- 但 `matches` 集合的文档没有 `organizerId` 字段（只有 `activityId`）
- **权限检查永远失败 → 返回 "仅组织者可更新比分"**

**修复方法：** 修改云函数 `match-live-score/index.js:31`，改为通过 activity 查找 organizerId：
```javascript
const act = await db.collection('activities').doc(match.data.activityId).get();
if (!act.data || act.data.organizerId !== openid) {
  return { success: false, message: '仅组织者可更新比分' };
}
```

---

### 问题 5：语音填分报错（action 不存在）

**链路追踪：**
- 前端 `grouping.js:216` 调用 `callFunction('voice-score-parse', 'recognize', { fileID, activityId })`
- 云函数 `voice-score-parse/index.js:44` 只支持 `parse` 和 `asr` action
- **`recognize` action 不存在 → 返回 "未知 action: recognize"**

**修复方法：** 修改 `grouping.js:216`，改为：
```javascript
callFunction('voice-score-parse', 'asr', {
  fileID: uploadRes.fileID,
  activityId: self.data.activityId
})
```

---

### 问题 6：语音识别永远失败（ASR 未配置）

**链路追踪：**
- 云函数 `voice-score-parse/index.js:37-39` 的 `tencentAsr` 函数
- 检查 `process.env.TENCENT_ASR_SECRET_ID` 和 `process.env.TENCENT_ASR_SECRET_KEY`
- 如果未配置，直接 `reject(new Error('ASR_NOT_CONFIGURED'))`
- **即使配置了，函数体也是空的（只有 reject），没有实际调用腾讯云 ASR**

**修复方法：** 需要实现 `tencentAsr` 函数的实际逻辑，或者在前端做降级处理（语音识别不可用时提示用户手动输入）。
