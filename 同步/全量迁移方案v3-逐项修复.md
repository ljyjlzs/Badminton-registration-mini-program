## 一、云函数返回值缺失（前端页面渲染会缺数据或报错）

### 1.1 get-activity-detail 云函数 — 缺 4 个字段

**文件：`cloudfunctions/get-activity-detail/index.js`**

**问题 A：缺少 `agentRegistrations` 返回**
- 前端 `activity-detail.js:111` 读 `data.agentRegistrations`
- WXML `activity-detail.wxml:141` 渲染 `agentRegistrations` 列表
- 云函数未返回此字段 → 代报名单永远为空

**修复方法：** 在 `detail` 对象中增加：
```javascript
agentRegistrations: regList.filter(r => r.agentUserId === openid && r.cancelStatus !== 'approved').map(r => ({
  id: r._id,
  nickname: r.nickname,
  level: r.level,
  cancelStatus: r.cancelStatus,
  applyStatus: r.applyStatus
}))
```

**问题 B：缺少 `agentNickname` 字段**
- WXML `activity-detail.wxml:103` 渲染 `{{item.agentNickname || '代报人'}}代报`
- `regVO` 不返回 `agentNickname` → 显示为空

**修复方法：** 在 `regVO` 中增加 `agentNickname`。需要在返回 registrations 时，根据 `agentUserId` 查找对应用户的 nickname。

**问题 C：缺少 `partnerNickname` 字段**
- WXML `activity-detail.wxml:104` 渲染 `{{item.partnerNickname || '已配对'}}`
- `regVO` 不返回 `partnerNickname` → 搭档名称永远显示"已配对"

**修复方法：** 在返回 registrations 时，根据 `partnerId` 查找对应用户的 nickname。

**问题 D：缺少 `globalBanner` 返回**
- 前端 `activity-detail.js:113` 读 `data.globalBanner`
- WXML `activity-detail.wxml:8-17` 渲染全局横幅
- 云函数未返回此字段 → 横幅永远不显示

**修复方法：** 查询 `matches` 集合中 status 为 `playing` 的比赛，构建 globalBanner：
```javascript
const playingMatch = (matches.data || []).find(m => m.status === 'playing');
const nextMatch = (matches.data || []).find(m => m.status === 'pending');
globalBanner: {
  currentText: playingMatch ? buildBannerText(playingMatch, '进行中') : '',
  nextText: nextMatch ? buildBannerText(nextMatch, '即将上场') : ''
}
```

### 1.2 submit-score 云函数 — 不支持修改已结束比赛

```javascript
if (action === 'modify') {

  // ... 撤销旧 rating、重新计算、更新比分
}
```

### 1.3 join-activity 云函数 — 代报逻辑缺失

**文件：`cloudfunctions/join-activity/index.js`**

**问题 A：** `if (!avatar) return { success: false, message: '请上传头像' }` — 代报名时代报人可能没有被代报人的头像

**修复方法：** 当 `agent === true` 时，允许 `avatar` 为空，使用默认值。

**修复方法：** 前端 `activity-detail.js` 代报提交时，payload 中需加 `agent: true`。

### 1.4 get-activity-report 云函数 — 四态状态机不完整

**问题：** 前端 `activity-report.js` 期望返回 `{ status: 'none'|'generating'|'finished'|'failed', report: {...}, badges: [...] }`，但云函数可能只返回部分。

**修复方法：** 确保云函数返回完整的四态状态。

### 1.5 get-user-stats 云函数 — 赛季/年度数据不完整
