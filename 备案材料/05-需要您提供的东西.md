 # 需要您提供的东西

## 一、必须提供（缺一不可）

### 1. 个人身份信息（个人备案）

| 材料 | 要求 | 用途 |
|------|------|------|
| 身份证正面照片 | JPG/PNG，清晰无反光，不超过 2MB | 主办单位证明 |
| 身份证反面照片 | JPG/PNG，清晰无反光，不超过 2MB | 主办单位证明 |
| 手持身份证照片 | 五官清晰 + 身份证信息清晰可见 | 身份核验 |
| 手机号 | 能接收短信验证码 | 备案验证 |
| 电子邮箱 | 常用邮箱 | 备案通知 |

**如果是企业备案：**
- 营业执照（统一社会信用代码）
- 法人身份证正反面
- 对公账户信息

### 2. 小程序名称
当前代码中使用的是"羽毛球"，建议改为更具体的名称，例如：
- 羽毛球竞赛管理
- 羽毛球活动助手
- 羽球赛事通

**请确认最终名称**，我帮你改代码。

### 3. 小程序图标
- 尺寸：144 × 144 像素
- 格式：PNG
- 圆角：微信会自动裁切为圆形
- 建议使用羽毛球相关图形

**如果你没有图标**，告诉我想要的风格，我帮你生成。

## 三、备案操作步骤

### 第 1 步：登录微信公众平台
1. 打开 https://mp.weixin.qq.com
2. 用微信扫码登录
3. 进入「设置」→「基本设置」

### 第 2 步：填写基本信息
1. 小程序名称
2. 小程序图标
3. 小程序简介
4. 服务类目选择：**体育 → 体育赛事**

### 第 3 步：进入备案流程
1. 点击「小程序备案」
2. 按提示填写主办单位信息
3. 上传身份证照片
4. 填写服务内容（复制本文件夹中的说明文档）

### 第 4 步：等待审核
- 备案审核通常需要 1-3 个工作日
- 可能会有电话核实，保持手机畅通
